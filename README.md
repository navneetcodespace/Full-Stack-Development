## 📚 Topics Covered

### 🧱 HTML5 - Web Structure

- **Head Tags** - Meta information, title, links, scripts
- **Text Formatting** - Semantic and presentational markup
- **Images** - Image embedding and optimization
- **Lists** - Ordered, unordered, and definition lists
- **Tables** - Data presentation with table structure
- **Links** - Navigation and hyperlinks
- **Forms** - Interactive user input (basic & advanced)
- **Semantic HTML** - Proper markup structure
- **Web Hosting** - Deploying applications online
- **Projects** - Resume website with multiple pages

### 🎨 CSS3 - Web Styling

- **CSS Fundamentals** - Syntax and integration methods
- **Selectors** - Element, class, ID, and advanced selectors
- **Colors & Units** - RGB, HEX, HSL, px, em, rem, etc.
- **Box Model** - Margin, padding, borders, and layout
- **Typography** - Fonts, text formatting, and styling
- **Layout Techniques** - Positioning and display properties

### 🔧 Additional Topics

- **Git & GitHub** - Version control and collaboration
- **Hoisting** - JavaScript variable and function hoisting

## 🚀 Getting Started

### Prerequisites
- A web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code, Sublime Text, or any text editor)
- Basic command line knowledge (for Git)

### Installation & Usage

1. **Clone the repository:**
   ```bash
   git clone https://github.com/navneetcodespace/Full-Stack-Development.git
   cd Full-Stack-Development
   ```

2. **Open any project:**
   - Navigate to the desired folder
   - Open the `.html` file directly in your browser
   - Or right-click → "Open with" → Select your browser

3. **View source code:**
   - Open files with your code editor to inspect the code
   - Read the accompanying `.txt` files for detailed notes and explanations

4. **Practice:**
   - Modify the code and experiment
   - Create your own variations
   - Build upon the examples provided
